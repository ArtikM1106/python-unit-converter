Конвертер единиц
Малыхин Артём — менеджер проекта и разработчик.
Иван Морев — тестировщик.

Цель и актуальность
Сделать настольное приложение для быстрого перевода единиц при решении задач и повседневных расчётах.

Задачи
Определить поддерживаемые единицы, реализовать формулы и интерфейс, построить диаграмму классов и проверить результат.

Функциональные требования
Выбор категории и двух единиц. Длина: метры, километры, сантиметры. Масса: граммы и килограммы. Температура: градусы Цельсия и Фаренгейта.
Ввод числа с точкой или запятой, расчёт по кнопке «Перевести», вывод результата с единицей. При неверном вводе отображается сообщение.

Нефункциональные требования
Одно окно, работа без интернета и сторонних пакетов. Результат отображается с точностью до 12 значащих цифр.

Технологии и структура
Python 3 подходит для простых формул. Tkinter позволяет собрать интерфейс стандартными средствами.
units.py содержит расчёты. LinearConverter скрывает коэффициенты, TemperatureConverter использует формулы температур. Оба класса реализуют метод convert базового Converter. Окно вызывает этот метод одинаково для всех категорий.
Диаграмма классов находится в classes.md. Запуск: python converter.py
